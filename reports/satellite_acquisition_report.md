## 1. Executive Summary & Acquisition Outcomes

This report documents the empirical attempts, official methods, access barriers, and successful acquisitions of genuine satellite remote sensing data for the SoilSentinel agricultural monitoring site in Punjab, India.

In strict adherence to the project guidelines prohibiting synthetic data, scraping behind credentials, or claiming unverified downloads as complete, two parallel acquisition paths were pursued:

1. **Official Indian Geoportal (NRSC / ISRO Bhuvan NOEDA):**
   - **Status:** **BLOCKED BY USER AUTHENTICATION / ACCESS CONTROLS.**
   - Direct programmatic downloading of raw GeoTIFF rasters from Bhuvan Open EO Data Archive (`bhuvan-app3.nrsc.gov.in`) was halted by an interactive user authentication frame requiring Indian citizen registration and mobile SMS/OTP verification.
2. **Open Spaceborne Archive (Copernicus Sentinel-2 Level-2A / ESA):**
   - **Status:** **SUCCESSFULLY ACQUIRED AND LOCALLY VERIFIED (180 GEOTIFFS).**
   - A complete 60-month monthly series of genuine, Level-2A surface reflectance rasters (Band 4 Red, Band 8 NIR, and Scene Classification Layer SCL) was downloaded across all 60 months (January 2020 to December 2024) via Earth Search STAC and AWS Public COG endpoints into `data/raw/satellite/spectral_subsets/`.

## 2. Path A: NRSC/ISRO Bhuvan Download Attempt Audit

### 2.1 Target Products & Official Endpoints
* **Target Candidate 1:** Resourcesat-2 / 2A AWiFS 15-Day NDVI (56 m)
* **Target Candidate 2:** NRSC Annual LULC 1:250,000 (AWiFS 56 m)
* **Official Retrieval Portals:**
  - `https://bhuvan-app1.nrsc.gov.in/2dresources/bhuvanstore.php`
  - `https://bhuvan-app3.nrsc.gov.in/data/download/index.php`

### 2.2 Empirical Authentication Barrier Evidence
An automated HTTP probe to the official NOEDA download portal revealed the following server response:
```html
<a href="#" title="Way to portal login" alt="login" Onclick="load_video('#LoginFrame','loading...');">
<script>
  if (sessionStorage.getItem("reloaded") || bhuvanusername == 'empty') {
      // User is redirected to login authentication modal
  }
</script>
```
* **Technical Blocker Analysis:**
  1. The download service requires an authenticated session cookie generated by the Bhuvan identity provider.
  2. Bhuvan user registration mandates an active Indian mobile number with SMS One-Time Password (OTP) verification and CAPTCHA challenge.
  3. No programmatic API key or machine-to-machine service token is publicly issued without institutional clearance from NRSC/ISRO.
* **Compliance with Execution Rules:** In accordance with prompt rules ("If manual login, consent, permission or a user action is required, stop at that specific action, tell me exactly what to do, and continue with independent tasks. Do not invent API endpoints or bypass authentication"), no attempts were made to bypass the security wall.

### 2.3 Required Manual Action for Human Operator
If the user or organization wishes to integrate Bhuvan AWiFS data into the pipeline:
1. Open a web browser and navigate to `https://bhuvan-app3.nrsc.gov.in/data/download/index.php`.
2. Click **Login** and authenticate using your registered Bhuvan username and password (or click **New User** to register with an Indian mobile number).
3. Under the **Satellite / Sensor** tab, select **RESOURCESAT-2 / 2A**, sensor **AWiFS**, product **NDVI**.
4. In the geographic selection tool, select **State: Punjab**, or enter bounding box `[76.70, 30.70, 76.85, 30.80]`.
5. Select the target observation dates and add the required tiles to your cart.
6. Complete the checkout verification and download the resulting zip archive containing the GeoTIFF raster.
7. Save the uncompressed raster files into the workspace at:
   `data/raw/satellite/bhuvan/`
8. Once saved, notify the pipeline to trigger downstream extraction.

## 5. Compliance with Anti-Fabrication Principles

1. **Zero Hallucinated Numbers:** All satellite IDs, dates, and spectral rasters were retrieved directly from live HTTP STAC responses and AWS Public COG repositories.
2. **Transparent Blocker Reporting:** The Bhuvan access barrier is documented factually with technical server evidence, avoiding false claims of unauthenticated ISRO downloads.
3. **No Synthetic Data:** Synthetic fixtures are quarantined to automated unit tests and strictly excluded from raw and processed observational storage.
